# Sound-Files für Station 6 · Instrumenten-Memory

Lege hier ein Audio-File pro Instrument ab. Der **Dateiname (ohne Endung)** wird
zum Anzeigenamen automatisch übersetzt (siehe `lib/memory.py → DISPLAY_NAMES`).

## Empfohlene Files

| Datei | Anzeigename |
|-------|-------------|
| `trompete.mp3`   | Trompete |
| `posaune.mp3`    | Posaune |
| `horn.mp3`       | Waldhorn |
| `tuba.mp3`       | Tuba |
| `fluegelhorn.mp3`| Flügelhorn |
| `saxophon.mp3`   | Saxophon |
| `klarinette.mp3` | Klarinette |
| `querfloete.mp3` | Querflöte |
| `oboe.mp3`       | Oboe |
| `euphonium.mp3`  | Euphonium |
| `kornett.mp3`    | Kornett |
| `bariton.mp3`    | Bariton |

## Anforderungen

- **Formate:** .mp3, .wav, .ogg, .m4a, .aac
- **Länge:** 2–4 Sekunden pro Sample sind ideal
- **Inhalt:** Möglichst neutrale Töne oder kurze Phrasen, damit das Timbre klar erkennbar ist
- **Lautstärke:** Alle Files gleich pegeln (normalisieren auf ca. −3 dBFS)

## Minimum

- **Einfach** (4 Paare) → 4 Files
- **Normal**  (8 Paare) → 8 Files
- **Schwer** (12 Paare) → 12 Files
